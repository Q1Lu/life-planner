# 📒 生活手帳 Life Planner

一個網頁就搞定：**行事曆（可與 Google 日曆同步）＋ 待辦（含截止倒數） ＋ 記帳 ＋ 習慣紀錄 ＋ 番茄鐘**。

純前端（HTML + CSS + JavaScript），不需要安裝、不需要後端伺服器。

## 檔案結構

```
index.html            網頁骨架（各分頁、彈出視窗的 HTML）
css/style.css         所有外觀樣式（深淺色、版面）
js/core.js            資料存取、共用小工具、分頁切換、深淺色
js/calendar.js        📅 行事曆（年／月／週／日／列表、拖曳、側邊選單、行程編輯）
js/todo.js            ✅ 待辦與截止倒數
js/money.js           💰 記帳
js/backup.js          匯出／匯入備份
js/google-calendar.js Google 日曆同步
js/drive-sync.js      Google 雲端硬碟資料同步
js/habits.js          時間格式工具、⏱ 計時習慣
js/daily-rank.js      每日任務、RANK 段位、Routine
js/health.js          ❤️ 健康（體重、血壓、InBody）
js/pomodoro.js        🍅 番茄鐘、頂部小計時器
js/food-db.js         常見食物營養資料庫（每份大約值）
js/diet.js            🥗 飲食（TDEE、蛋白質目標、餐點紀錄、選用的 AI 分析）
js/workout.js         🏋️ 健身（依目標身材排每週菜單）
js/main.js            啟動（最後載入）
```

JS 檔是一般的 `<script>`（不是 module），依 `index.html` 裡的順序載入、共用同一組全域變數，所以**順序不能亂換**；新增檔案時放在 `main.js` 前面。

## 功能

| 分頁 | 功能 |
|---|---|
| 📅 行事曆 | 年／月／週／日／行程列表 五種檢視（電腦版左側固定側邊欄、手機版按左上 ☰ 滑出，可切換視圖並勾選要顯示的日曆）；週、日檢視是時間軸，可直接拖曳編輯；行程可設時間、顏色、備註、每週／每月／每年重複；待辦的截止日也會顯示；可與 Google 日曆雙向同步 |
| ✅ 待辦 | 截止日＋截止時間（沒填時間 = 當天 23:59:59）、優先度、篩選；每項顯示距離截止還有多久的**即時倒數，精確到千分之一秒**（剩不到 24 小時變橘色、不到 1 小時或已逾期變紅色），依截止時間排序；**點待辦文字可編輯**內容、截止日／時間、重要性 |
| 💰 記帳 | 收入／支出、分類、每月統計與分類長條圖 |
| 🏃 習慣 | **RANK 段位（經驗值 XP）**：習慣、番茄鐘、待辦都能加分——每日任務完成 80% 以上 +10（全部完成 +15）、每專注 5 分鐘 +1（一個番茄 +5）、完成待辦 +5（重要 +10，準時再 +3）；段位：青銅 0 → 白銀 150 → 黃金 600 → 白金 1,800 → 鑽石 4,000 → 大師 8,000。網站左上角隨時顯示目前段位＋**今日任務**：依群組（作息、飲食、保健、morning routine…）列出每天要做的事，可切換日期補勾。項目類型：✅ 打勾、🔢 計數（例如喝水 1500/3000 ml）、⏱ 計時（連到計時習慣）、💊 保健（早／午／晚、必吃）；可設定哪幾天要做（每天／平日／自選）。Routine 群組按 ▶ 會一步一步帶你做。按「✏️ 編輯」可新增、修改、刪除、排序群組和項目。下方保留計時習慣（例如健身房）的每週／每月統計 |
| 🍅 番茄鐘 | 專注／短休息／長休息（時間可調）；可選「正在處理哪項待辦」，時間到自動記到那項工作上；可提早「結束並記錄」；統計每項工作花了多少時間（今天／本週／全部）。待辦清單每項都有 🍅 按鈕可直接開始，並顯示累計時間 |
| ❤️ 健康 | 每天記錄體重、早／晚血壓（含脈搏），InBody 報告的體重、骨骼肌、體脂肪、體脂率、BMI、內臟脂肪、基礎代謝、分數；體重與血壓趨勢圖（30 天／90 天／1 年）、InBody 第一次 → 最新一次的變化。血壓分級依台灣 2022 高血壓指引，僅供參考 |
| 🥗 飲食 | 填性別、年齡、身高、活動量（體重自動抓健康頁最新一筆），算出基礎代謝、**TDEE**、每日建議熱量（有目標體重時自動算減脂／增肌）、**蛋白質目標（體重 × 1.6–2.0 g）**。打字輸入吃了什麼（例如「雞腿便當、半糖珍奶、兩顆茶葉蛋」），從內建食物資料庫估算熱量、蛋白質、碳水、糖、脂肪、纖維、鈉，可調整份量後記錄成早餐／午餐／晚餐／點心，並顯示當天跟目標的比較。資料庫找不到的，可以手動輸入，或設定自己的 Claude API 金鑰用 **AI 分析**任何中文描述（金鑰只存在該裝置的瀏覽器，不會同步） |
| 🏋️ 健身 | 選目標體重、想要的身材（六塊肌、人魚線、倒三角、胸肌、手臂、翹臀、腿部線條、整體減脂、增肌）、器材（健身房／啞鈴／居家徒手）、程度和每週天數，自動排出每週菜單：每天做哪些動作、幾組、幾下、休息多久，重點部位會標出來並多一組 |

計時中切到其他分頁，最上方會出現小計時器（🍅 番茄鐘、💪 習慣），點一下就回到該分頁。關掉網頁再打開，計時也會接續。

### 週／日 時間軸怎麼操作

| 動作 | 電腦（滑鼠） | 手機 |
|---|---|---|
| 新增行程 | 點空白時段，或在空白處拖出一段時間 | 點空白時段；或長按空白處再往下拖 |
| 編輯行程 | 點一下行程 | 點一下行程 |
| 移動（換時間／換天） | 拖曳行程 | 長按行程約半秒，震動後拖曳 |
| 調整結束時間 | 拖行程底邊 | 長按行程底邊後拖曳 |
| 切換日／週 | 點上方日期 | 點上方日期 |

拖曳以 15 分鐘為單位移動，原本的分鐘數會保留（例如 09:10 的課拖動後仍是 xx:10）。唯讀日曆的行程不能拖。

右上角的「🌗 自動／☀️ 淺色／🌙 深色」按鈕可切換整個網站的深淺色（自動 = 跟著系統設定）。

右上角「匯出／匯入」可備份成 JSON 檔，用來搬到別的瀏覽器或裝置。

## 隱私

這個 repo 是公開的，但裡面**只有程式碼**。你輸入的待辦、習慣、健康數據等資料只存在你的瀏覽器和你自己 Google 雲端硬碟的隱藏 App 資料夾，別人打開這個網站看到的是空的。

## 資料存在哪裡？

- **行事曆（連上 Google 後）**：存在你選擇的 Google 日曆。
- **待辦、記帳、習慣、番茄鐘紀錄、本機行程**：存在瀏覽器裡，**連上 Google 後會自動同步到你的 Google 雲端硬碟**，所以電腦和手機登入同一個 Google 帳號就會看到一樣的資料。
  - 存在雲端硬碟「這個 App 專用的隱藏資料夾」（appDataFolder），你在雲端硬碟裡看不到它，這個網站也讀不到你其他的檔案。
  - 兩台裝置都改過時，**逐筆比較最後修改時間**，較新的留下；刪除也會同步。
  - 修改後約 1.5 秒自動上傳；切回網頁時、以及每分鐘會自動下載別台裝置的變更。右上角「☁️ 已同步」點一下可立即同步。
- 只存在單一裝置的：深淺色、目前檢視、番茄鐘正在跑的計時、習慣正在跑的計時。
- 沒連 Google 時，也可以用「匯出／匯入」手動搬資料。

## 使用方式

- 線上版（GitHub Pages）：<https://q1lu.github.io/life-planner/>
- 本機：在資料夾執行 `python -m http.server 8765`，開啟 <http://localhost:8765>
  （直接雙擊 `index.html` 也能用，但 Google 登入需要 http/https 網址，所以要同步時請用上面兩種方式）

## 設定 Google 日曆同步

Google 需要一組你自己的 **OAuth Client ID**，只要設定一次：

1. 打開 [Google Cloud Console](https://console.cloud.google.com/)，建立一個新專案（名字隨意，例如 `life-planner`）。
2. 左側選單 **API 和服務 → 程式庫**，搜尋 **Google Calendar API**，按「啟用」。
3. **API 和服務 → OAuth 同意畫面**（或「Google Auth Platform」）：
   - 使用者類型選 **外部**，填應用程式名稱和你的 email。
   - 在「目標對象／測試使用者」加入**你自己的 Gmail**（應用程式維持「測試中」狀態就好，不用送審）。
4. **API 和服務 → 憑證 → 建立憑證 → OAuth 用戶端 ID**：
   - 應用程式類型：**網頁應用程式**
   - **已授權的 JavaScript 來源** 加入：
     - `https://q1lu.github.io`
     - `http://localhost:8765`（本機測試用）
   - 不需要填「重新導向 URI」。
5. 複製產生的 Client ID（長得像 `1234-abcd.apps.googleusercontent.com`）。
6. 開啟網站 → 右上角 **🔗 連接 Google 日曆** → 貼上 Client ID → 按「連接」→ 登入並允許存取日曆。
   - 出現「Google 尚未驗證這個應用程式」是正常的（因為是你自己的測試 App），按「繼續」即可。

> 想讓每台裝置都不用再貼一次？把 Client ID 填進 `index.html` 裡的 `const GOOGLE_CLIENT_ID=''` 再推上 GitHub。Client ID 不是密碼，公開也沒關係。

### 同步規則

- 連線後，新增的行程會**直接建立在 Google 日曆**；在這裡修改或刪除 Google 行程，也會同步回 Google。
- **選擇日曆**：
  - 在行事曆左上角 **☰ 側邊選單**勾選**要顯示的日曆**（預設只有主要日曆；也可以顯示節日、別人分享給你的日曆），也可以隱藏本機行程、待辦。
  - 在「🟢 Google 日曆」設定視窗（或側邊選單的 ⚙️）設定**新行程預設寫入**哪個日曆。
  - 新增或編輯行程時，也可以在「日曆」欄位改選，修改時選別的日曆會把行程搬過去。
  - 唯讀日曆（例如節日）只能看，不能在這裡修改。
  - 行程顏色不選的話，會使用該日曆在 Google 上的顏色。
- 在 Google 日曆（手機 App、網頁）新增的行程，會在切換月份、回到頁面或每 5 分鐘自動更新。
- 連線前建立的本機行程，可以在設定視窗按「把本機行程上傳到 Google 預設日曆」。
- Google 的重複行程，在這裡修改／刪除只會影響「那一次」。
- 基於安全，Google 授權每小時會過期，按上方「🔄 重新連線 Google」一下即可。
